=== 示例：推理吞吐量计算 ===
参数:
  Batch Size = 48
  序列长度   = 3072
  单步耗时   = 3.0 s
  Checkpoint 间隔 = 每 5 步
  Checkpoint 耗时 = 1.5 s

计算:
  每步 Token 数 = 48 x 3072 = 147,456
  5 步总 Token  = 147,456 x 5 = 737,280
  5 步总耗时   = 5 x 3.0 + 1.5 = 16.5 s
  吞吐量       = 737,280 / 16.5 = 44,684 token/s
                ≈ 44.7k token/s

答案: B (44.7k token/s)
