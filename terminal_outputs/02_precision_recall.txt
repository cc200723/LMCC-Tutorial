=== 示例：精确率与召回率计算 ===
混淆矩阵:
  TP (真阳性) = 80
  FP (假阳性) = 20
  FN (假阴性) = 40
  TN (真阴性) = 60

计算:
  精确率 (Precision) = TP / (TP + FP) = 80 / 100 = 0.8000
  召回率 (Recall)    = TP / (TP + FN) = 80 / 120 = 0.6667
  准确率 (Accuracy)  = (TP+TN) / Total = 140 / 200 = 0.7000
  F1 分数            = 2 x P x R / (P + R) = 0.7273

答案: B (精确率≈0.80, 召回率≈0.67)
