# LMCC 青少年组——人工智能与大模型能力认证教材

本书面向准备参加 LMCC 青少年组（大模型能力认证） 的学生，适用年龄大致在 8–18 岁。我们假设你此
前没有系统学习过人工智能或深度学习，因此每一章都从最基础的概念讲起，遇到公式和代码会先解释“它到
底在算什么”，再给出可运行、可检查的示例。

本书的创作合理运用了Agent工具，主要采取Workbuddy+Dumate .
